# Reconstruction service

MHR proof-of-concept adapters live here. `export_mhr_glb.py` asks the official local viewer to reset to neutral LOD 1 and export its skinned GLB; `validate_glb.py` checks its geometry, joint hierarchy and weights. The viewer owns shared mutable state, so run exports only when nobody else is editing it. See [MHR setup](../../docs/setup/mhr.md) for exact commands and limitations. The `reconstruct.py` adapter wraps the official SAM 3D Body estimator. `sam3d_mhr_adapter.py` checks saved SAM fields against an MHR evaluation before calling the official skinned GLB exporter. Both have run end to end on one authorized photo; their unit tests still use mocks and synthetic parameters. `probe_detectron2_cuda.py` and `probe_sam3d_initialization.py` check the WSL environment before a run. `profile_reconstruction.py` records per-stage GPU and host memory, optionally releasing the detector before SAM loads, and `analyze_body_shape.py` attributes posture and torso shape to identity, scale or pose (see the [Sprint 0.5 report](../../docs/sprint-0/sprint-0.5-report.md)). `sam3d-cu126-freeze.txt` records the package set that ran. See the [Sprint 0.3 report](../../docs/sprint-0/sprint-0.3-report.md), [SAM 3D Body setup](../../docs/setup/sam-3d-body.md) and the [integration analysis](../../docs/architecture/sam3d-mhr-integration.md).
