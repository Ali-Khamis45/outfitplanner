# Reconstruction service

MHR proof-of-concept adapters live here. `export_mhr_glb.py` asks the official local viewer to reset to neutral LOD 1 and export its skinned GLB; `validate_glb.py` checks its geometry, joint hierarchy and weights. The viewer owns shared mutable state, so run exports only when nobody else is editing it. See [MHR setup](../../docs/setup/mhr.md) for exact commands and limitations. The preliminary `reconstruct.py` adapter wraps the official SAM 3D Body estimator; it has not yet been tested with a checkpoint or actual photograph. See [SAM 3D Body setup](../../docs/setup/sam-3d-body.md) for access, environment and output details.
