# Reconstruction service

MHR proof-of-concept adapters live here. `export_mhr_glb.py` asks the official local viewer to reset to neutral LOD 1 and export its skinned GLB; `validate_glb.py` checks its geometry, joint hierarchy and weights. The viewer owns shared mutable state, so run exports only when nobody else is editing it. See [MHR setup](../../docs/setup/mhr.md) for exact commands and limitations. The preliminary `reconstruct.py` adapter wraps the official SAM 3D Body estimator; it has not yet been tested with a checkpoint or actual photograph. `sam3d_mhr_adapter.py` checks saved SAM fields against an MHR evaluation before calling the official skinned GLB exporter. Its tests use synthetic parameters, not real SAM outputs. See [SAM 3D Body setup](../../docs/setup/sam-3d-body.md) and the [integration analysis](../../docs/architecture/sam3d-mhr-integration.md) for the blocked end-to-end path.
