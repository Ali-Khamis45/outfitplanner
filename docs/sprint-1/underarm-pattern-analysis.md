# Sprint 1.2 underarm pattern analysis

This is an investigation, not an approved pattern. See `deformation-analysis.md` for the full Sprint 1.1 region and influence analysis. The existing A-pose voxel volume fuses the sleeve and torso near the axilla; the resulting short edges must bridge regions with different motion. The skin transfer and narrow double shell contribute to the deformation. Correct inverse binds alone do not solve it. A genuine extra panel or raised-arm construction remains unimplemented and must be tested; the evidence does not establish which would work.

At both +90 degrees the v3-close1 worst face is 44265, vertices 28842/28039/28038, rest centre (0.210, 1.275, -0.079) m, 10.87x stretch. Its averaged dominant weights are left upper-arm twist2 0.361, twist0 0.330, clavicle 0.189, twist1 0.078 and spine2 0.041. Face 121307 (vertices 64142/63987/64297) is the adjacent shell counterpart at approximately the same location and stretch. Face 44346 (29248/28861/28860), at (0.216, 1.304, 0.051) m, reaches 10.52x. Full per-pose distributions and six worst faces per pose are in the ignored `outputs/garment-tests/quality-v1-neutral+v3-close1-neutral.json`.

Its mean influences are left upper-arm twist2 0.334, twist0 0.288, clavicle 0.238, spine2 0.093 and twist1 0.047. The nearby v2 face 59670 (28835/29228/28839) has the same peak ratio. Face IDs refer to each exported mesh's own indexing and are not interchangeable between versions.

v3-close1 changes only the existing volume morphological closing radius from two voxels to one, using the v2 weight-transfer settings. This is a topology sensitivity experiment, not an explicit gusset or raised-pose pattern. It did not remove the limiting deformation, so no claim of corrected coverage is justified. No new global skin-weight smoothing experiment was performed. The shell has four openings (genus 3 closed double shell), nominal 2 mm thickness, UVs and normalized four-influence skinning. Its approximate minimum rest clearance is 5.99 mm; nearest-surface clearance has approximately 2 mm uncertainty.
