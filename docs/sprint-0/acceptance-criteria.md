# Sprint 0 acceptance criteria

- Record reproducible environment, dependency revisions, licenses and model access conditions.
- Run a real single-person photo through SAM 3D Body and preserve evidence of inputs, configuration, outputs, timing and peak memory locally.
- Verify the output's MHR representation and produce a GLB with a real skeleton and skin weights, inspecting the exported asset independently.
- Load the exported GLB in React Three Fiber, confirm rendering and at least one meaningful rig/pose interaction, and save a local screenshot.
- Document limitations, errors, hardware results, and whether the objective is achievable. Private inputs and outputs stay out of Git.

None of the reconstruction, export or viewer criteria have been demonstrated yet.
