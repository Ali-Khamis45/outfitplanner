# Project instructions

- Sprint 0 is a research proof of concept. Do not add authentication, payments, wardrobe management, or an ASP.NET backend.
- Report experiments and failures honestly; do not imply inference, rigging, export, or rendering works until verified.
- Use strict TypeScript, Python type hints, modular components, explicit errors, and reproducible commands. Run relevant checks.
- Keep personal imagery, tokens, local environment files, checkpoints, model assets, generated avatars, and output artifacts out of Git. Ignore rules are a safeguard, not a substitute for reviewing staged files.
- Use official upstream documentation, record external research dependency licenses and revisions, and do not silently change upstream code or licenses.
- Do not overwrite unrelated files. Keep research repositories in `external/` and private inputs and outputs in their ignored directories.
